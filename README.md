# ПГУ: Экономика — твой выбор

Профориентационное PWA направления «Экономика» ПГУ им. Шолом-Алейхема: тесты для школьников и студентов СПО/бакалавриата/магистратуры, подсчёт соответствия по профессиям, работа офлайн.

## Стек

React 18 + TypeScript + Vite + Tailwind CSS 4 + vite-plugin-pwa (Workbox) + Vitest + Playwright.

## Команды

```bash
npm install        # установка зависимостей
npm run dev        # режим разработки
npm run test       # модульные тесты (Vitest)
npm run test:e2e   # сквозные тесты (Playwright, нужен сборка)
npm run build      # production-сборка в dist/
npm run preview    # локальный просмотр сборки (http://127.0.0.1:4173)
```

## Деплой (Vercel)

1. Репозиторий подключается к Vercel.
2. Build Command: `npm run build`; Output Directory: `dist`.
3. После деплоя проверить: HTTPS, установку PWA, standalone-режим, офлайн-поведение.

## Структура данных

- `src/data/directions.json` — направления подготовки.
- `src/data/professions.json` — профессии (id, название, описание).
- `src/data/tests.json` — вопросы (`questions`) и тесты (`tests`) со ссылками на вопросы.

Каждый опубликованный тест обязан содержать ровно 20 вопросов и проходить валидацию `npm run test` (`tests/data.test.ts`): уникальность id, существование профессий в `scores`, покрытие обеих аудиторий.

## Методика результата

Каждый вариант ответа начисляет баллы одной или нескольким профессиям. Итог нормируется к достижимому максимуму и показывается как процент соответствия модели теста (не научный прогноз). Показываются наиболее и наименее подходящие профессии.
