# ПГУ: Экономика — твой выбор

Профориентационное PWA направления «Экономика» ПГУ им. Шолом-Алейхема: тесты для школьников и студентов СПО/бакалавриата/магистратуры (шкала 1–5), подсчёт соответствия по 20 профессиям, галерея профессий, направления подготовки, клуб молодого предпринимателя, работа офлайн.

## Стек

React 18 + TypeScript + Vite + Tailwind CSS 4 + vite-plugin-pwa (Workbox) + Vitest + Playwright.

## Команды

```bash
npm install        # установка зависимостей
npm run dev        # режим разработки
npm run test       # модульные тесты (Vitest)
npm run build      # production-сборка в dist/ (нужна перед test:e2e)
npm run test:e2e   # сквозные тесты (Playwright, использует npm run preview)
npm run preview    # локальный просмотр сборки (http://127.0.0.1:4173)
```

## Деплой (Vercel)

1. Репозиторий подключается к Vercel.
2. Build Command: `npm run build`; Output Directory: `dist`.
3. После деплоя проверить: HTTPS, установку PWA, standalone-режим, офлайн-работу.

Приложение — одна страница без клиентских маршрутов, поэтому SPA-rewrite не требуется; офлайн-переходы по URL обслуживает service worker (Workbox `NavigationRoute → index.html`).

### Другие статические хостинги

Подходит любой хостинг со статическими файлами по HTTPS:

- **Netlify** — Build Command `npm run build`, Publish Directory `dist`.
- **GitHub Pages** — задать `base` в `vite.config.ts` (например, `base: "/имя-репозитория/"`) перед сборкой; HTTPS включён автоматически.

Требования к хостингу: HTTPS (обязательно для service worker), корректный MIME-тип `.webmanifest` (`application/manifest+json`) — стандартные хостинги обеспечивают. Обновления подхватываются автоматически (`registerType: "autoUpdate"`).

## Структура данных

- `src/data/directions.json` — направления подготовки.
- `src/data/programs.json` — четыре программы подготовки (38.02.07, 38.02.01, 38.03.01, 38.04.01); разделы описаний — заглушки до заполнения.
- `src/data/professions.json` — 20 профессий (id, программа `programId`, название, описание).
- `src/data/professionDetails.json` — карточки галереи: обязанности, навыки, особенности (`null` — «информация готовится»).
- `src/data/tests.json` — вопросы со знаковыми весами профессий (`questions`) и тесты (`tests`) со ссылками на вопросы.

Каждый опубликованный тест обязан содержать ровно 20 вопросов и проходить валидацию `npm run test` (`tests/data.test.ts`): уникальность id, существование профессий в весах, покрытие обеих аудиторий, распределение профессий по программам.

## Методика результата

Ответ на вопрос — оценка по шкале 1–5 («Совсем не моё» … «Абсолютно моё»). Веса заданы единой моделью для всех 20 профессий: каждый вопрос относится к одному из 12 признаков, у каждой профессии есть профиль по этим признакам, вес = значение профиля по признаку вопроса. Балл профессии за вопрос: `w × (ответ − 3)`; процент соответствия — нормировка к достижимому диапазону: `(raw − min) / (max − min) × 100` (50 — нейтрально). Пропущенные вопросы исключаются из расчёта. Подробно, со сверкой с исходной методикой и контрольными примерами — в `docs/scoring-methodology.md`.
